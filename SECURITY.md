# Security Policy

## Kebijakan Pelaporan Kerentanan (Vulnerability Disclosure)

Keamanan informasi data statistik dan portal kedinasan BPS Kabupaten Solok Selatan merupakan prioritas utama. Jika Anda menemukan indikasi celah keamanan atau kerentanan teknis pada aplikasi ini, mohon bantu kami dengan melaporkannya secara bertanggung jawab (*responsible disclosure*).

### Versi yang Didukung

Hanya versi terbaru pada branch `main` yang aktif menerima pembaruan patch keamanan:

| Versi | Didukung |
| :--- | :--- |
| `main` (Latest) | :white_check_mark: |
| < 0.1.0 | :x: |

### Cara Melaporkan Kerentanan

1. **JANGAN** membuat *public issue* di GitHub untuk melaporkan kerentanan keamanan yang belum tertangani.
2. Silakan kirimkan laporan Anda melalui fitur **Private Vulnerability Reporting** di tab **Security** repositori GitHub ini, atau hubungi tim pengelola teknis BPS Kabupaten Solok Selatan melalui email resmi dinas.
3. Cantumkan informasi berikut dalam laporan Anda:
   - Deskripsi singkat mengenai jenis kerentanan (misal: CSRF, XSS, broken access control).
   - Langkah-langkah reproduksi (*proof of concept* tanpa merusak data/layanan).
   - Dampak potensial terhadap sistem atau data pengguna.
   - Saran mitigasi atau patch (jika ada).

### Komitmen Respon Kami

- Tim teknis akan meninjau dan mengonfirmasi laporan awal dalam waktu **1-3 hari kerja**.
- Perbaikan/patch keamanan akan diuji dan dirilis secepatnya melalui rilis versi terbaru.
- Pelapor yang mempraktikkan pengungkapan bertanggung jawab akan dihargai atas kontribusinya dalam menjaga integritas portal.
